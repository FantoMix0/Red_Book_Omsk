# 🌿 Красная книга Омской области — интерактивная карта

Интерактивный веб-атлас видов Красной книги Омской области: карта с маркерами,
ареалами и путями миграции, справочник видов, полевой дневник и обучающие мини-игры.

Проект не требует сборки — это статический HTML/CSS/JS, который можно открыть
напрямую (данные для режима `file://` встроены в `js/species-data.js`) или
через любой локальный сервер.

---

## 🚀 Запуск

### Вариант 1: Live Server / локальный сервер (рекомендуется)

```bash
# из корня проекта
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

или в VS Code — расширение **Live Server** → «Open with Live Server».

### Вариант 2: просто открыть `index.html`

Работает в урезанном режиме (без загрузки GeoJSON через fetch), данные видов
берутся из `window.SPECIES_DATA`.

---

## 🗺 Возможности

| Раздел | Описание |
|---|---|
| **Карта** | Несколько вариантов подложки, маркеры наблюдений, области ареалов, линии миграций |
| **Категории редкости** | Фильтрация видов по статусу 0–5 (вероятно исчезнувшие … наименее уязвимые) |
| **Справочник** | Полный список всех видов, сгруппированный по систематическим группам |
| **Режим разработчика** | Рисование областей и миграций, серийный режим добавления маркеров (по паролю) |
| **Полевой дневник** | Личные записи наблюдений с фотографиями, сохраняются в браузере |

## 🎮 Мини-игры

Все игры доступны через меню «Игры» в боковой панели (в видимом режиме) и используют
данные о видах из базы Красной книги:

| Игра | Файлы | Правила |
|---|---|---|
| 🎲 **Викторина** | `js/quiz.js`, `css/quiz.css` | Угадайте вид по фотографии на время; счёт верных/неверных ответов и серия 🔥 |
| 🧩 **Найди пару** | `js/match.js`, `css/match.css` | Соедините карточку с фото вида с его названием (10 пар); в конце — достижения |
| 🃏 **Мемо** | `js/memo.js`, `css/memo.css` | Классические «парочки»: переворачивайте карты и запоминайте расположение (12 пар) |
| 🜁 **Латынь** *(новая)* | `js/latin.js`, `css/latin.css` | Соедините русское название вида с его латинским. 3 раунда по 5 пар, таймер 45 с на раунд, серии за идеальные раунды и достижения («Хранитель латыни» и др.) |

## 🧬 Формат данных о виде

Каждый вид имеет уникальный `id` (латинское название в нижнем регистре,
например `acipenser_baerii`). Фото — `img/species/<id>.png`, подробный текст —
`data/species/<id>.json` либо встроенный `window.SPECIES_DATA`.

Основные поля: `id`, `name` (русское название), `latin` (латынь с автором),
`status` (категория редкости 0–5), `status_text`, `order`, `family`, описания.

## 🛠 Как добавить новую мини-игру

1. Создайте `js/<game>.js` по образцу `js/latin.js`: объект игры с методами
   `init/open/close/startGame`, получение видов через `App.collectAllSpecies()`.
2. Добавьте кнопку в блок `#games-menu` в `index.html` и модалку игры.
3. Подключите `<script>` и `<link>` в конце `index.html`.
4. Игра должна вызывать `LatinGame.init()`-подобную инициализацию после
   `DOMContentLoaded` с проверкой, что `App` загружен.

## 📝 Скрипты обслуживания

- `scripts/import.py`, `scripts/fill_status_text.py` — импорт и обогащение данных видов;
- `scripts/merge.html` — утилита объединения данных.

## ⚠️ Примечания

- Все пользовательские данные (дневник, нарисованные объекты) хранятся локально
  в `localStorage` браузера и не отправляются на сервер.
- Проект рассчитан на современный браузер (ES6+, CSS Grid, clip-path).
